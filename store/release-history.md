# 历史公告

## 1.0.0 - 2026-07-31

WebFile Hunter 现已进入首个稳定正式版。侧栏无论从哪里打开，都能识别所在窗口当前的普通 HTTP/HTTPS 网页；标签页权限只用于读取当前 URL 与标题。当前页和递归扫描继续按站点授权；完整实时嗅探只在用户点击后单独请求可撤销的 HTTP/HTTPS 全站权限，并始终限定在当前标签页。

正式版修复了多窗口侧栏串站点、首次侧栏扫描无法注入、超大网页整批结果被拒绝、图片开关在不同发现管线行为不一致等问题。完整嗅探现可发现第三方 CDN、无扩展名非 HTML 响应和跨域 frame 资源；递归页面直接使用 GET，并能从 robots.txt Sitemap 与当前 SPA 已渲染 DOM 补充同源页面。页面标题、URL 和单批资源均在内容端安全限界。

`blob:` 临时资源仍会出现在独立“可能资源”分类，但无效的打开、元数据探测和下载操作已全部禁用。任务控制期间会阻止重复点击；键盘焦点更加清晰，reduced-motion 下不再运行无限旋转动画。

真实 Microsoft Edge E2E 已验证未授权网站识别与权限隔离、当前页扫描、实时监听、Sitemap 隐藏页、拒绝 HEAD 但允许 GET 的页面、SPA 运行时路由、TXT/CSV/JSON 与历史导出、下载真实落盘、五页窄侧栏和数据清理。扩展仍完全本地运行，不上传扫描数据，默认静音，不播放音效或背景音乐。

## 0.2.3 - 2026-07-31

本次版本补齐临时媒体发现与递归扫描实时进度：页面内 `blob:` 资源现在会安全进入结果库，并在独立“可能资源”分类中显示数量、临时资源警告和人工确认提示；它们始终不可下载，也不会进入后台网络访问或下载队列。

递归扫描会实时显示当前正在请求的 URL 和最近一分钟真实请求数，慢请求结束后会清除过期速率。侧边栏现在正确合并进度事件，任务完成、失败或取消后立即移出未完成列表；迟到的运行事件不会再把终态任务回退为运行中。

UI 增加清晰的按钮按压反馈并完整遵守 reduced-motion。真实 Microsoft Edge E2E 已实际完成 TXT、CSV、JSON、历史导出与下载队列落盘，同时检查 280px、320px、380px 侧栏、可访问名称、按钮目标尺寸，以及清空历史不会误删下载记录和设置。

WebFile Hunter 仍完全本地运行，不上传扫描数据，默认静音，不播放音效或背景音乐。

## 0.2.2 - 2026-07-30

本次版本继续加固任务生命周期与本地数据安全：同一标签页即使跨 Origin 导航也不会叠加扫描；活动映射写入、任务结束和浏览器启动清理按序执行。递归扫描在顶层异常、暂停检查点失败或后台重启且无法恢复时会进入统一失败终态，暂停任务恢复也会拒绝非法状态和并发操作。

清除全部本地数据前会确认启动中的下载已获得 Edge 下载 ID；若活动下载无法取消，任务记录会保留并显示错误，不再造成“记录已删但下载仍继续”的错觉。当前页 iframe 迟到结果仅在短暂收集窗口内接收，过期结果不会继续修改已完成任务。

结果列表现在会跟随窗口高度调整，超长 MIME、全部来源和风险标签在 280px、320px、380px 窄侧栏下也不会裁掉操作按钮。真实 Edge E2E 已覆盖三档宽度、极端内容和底部遮挡。

WebFile Hunter 仍完全本地运行，不上传扫描数据，不默认播放音效或背景音乐。

## 0.2.1 - 2026-07-29

本次版本完成一次发布级稳定性、安全与 UI 深度加固：活动标签页快照和实时事件现在严格隔离，不会混入其他标签页任务；同标签页扫描互斥，旧任务也不会清除新任务映射。下载页会从 Edge 同步真实进度，后台恢复时校准陈旧任务，清除全部数据前会先取消活动下载。当前页扫描增加超时看门狗，窗口聚焦、标签页导航和 Service Worker 恢复链路也已补齐。

设置页会保留未保存草稿；结果来源与风险提示全面中文化，并补充单项复制/打开失败反馈、分类状态和键盘焦点。动态资源属性识别、IPv4-mapped IPv6 私网防护、可取消网络退避以及 320px/380px 窄侧栏布局同步增强。
