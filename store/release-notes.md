# 1.7.0

WebFile Hunter 1.7.0 进一步扩大并严格整理文件发现结果。JavaScript、CSS、TypeScript 与 WASM 进入独立“源码”分类，WOFF/WOFF2/TTF/OTF/EOT 进入“字体”分类；`.ts` 会按页面标签和请求语义区分 TypeScript 与 MPEG-TS。通用文本、二进制和 ZIP 容器 MIME 不再覆盖字幕、文档或电子书等更具体后缀，HLS/DASH 清单会明确标记为不可直接下载的分段媒体，自定义 MIME 支持 `model/*` 一类通配符。

递归扫描新增同路径查询参数变体上限，避免日历、筛选器和分页参数形成无界抓取陷阱。用户可分别控制 Sitemap 发现与网页文字提取，并配置请求超时、最大重定向及是否跟随重定向；当前页、实时监听和递归任务会固定使用启动时的正文配置，关闭样式表扫描时各条发现链路行为一致。

每个结果现在都有独立“详情”，可查看分类、置信度、扩展名、大小、MIME、资源 URL、来源页、发现方式与风险，并复制文件名、Markdown 链接或元数据 JSON。详情中的资源与来源页会在新标签页打开，失败时保留弹层并显示真实错误；背景使用原生 `inert`，Escape、焦点闭环和关闭后焦点返回均已验证。图片缩略图、放大预览、音频时长与手动试听继续保留，媒体卡在极窄侧栏下完整显示 7 个操作。

真实 Microsoft Edge E2E 已验证 29 个当前页候选、9 页/37 个递归候选、源码/字体分类、Sitemap、正文隐私过滤、高级设置保存回读、图片与音频实际加载、详情操作、资源打开、单项下载真实落盘及 280/320/380px 六页界面。扩展继续完全本地运行，默认静音，不播放 SFX 或 BGM；音频只响应用户点击。
