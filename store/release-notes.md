# 1.10.0

WebFile Hunter 1.10.0 加固完整实时嗅探。用户配置的自定义扩展名现在会直接参与网络请求候选判断，即使资源响应没有 MIME 或 Content-Disposition，`.meshx` 一类文件也不会漏掉；普通无后缀 GET 不会因此增加多余的持久化查询。

已完成元数据的文件可以可靠重新探测。状态写入会同时校验任务与文件归属，并准确经历探测中、完成或失败，不再被候选去重逻辑错误保留为旧的完成状态。设置保存期间也会锁定全部可编辑参数，避免较慢的保存响应覆盖用户新草稿。

本版再次逐项复查结果卡、图片缩略图、音频手动试听、预览弹层、新标签页打开、独立下载、历史、设置、键盘焦点、reduced-motion 和 280/320/380px 窄侧栏。扩展继续完全本地运行，默认静音，不播放 SFX 或 BGM；音频只响应用户点击。

发布回归覆盖全量单元与组件测试、覆盖率、TypeScript、ESLint、Prettier、Manifest、生产构建、发布 ZIP 和真实 Microsoft Edge E2E，并新增自定义扩展网络嗅探及元数据重新探测状态流转验证。
