# 0.2.3

本次版本补齐临时媒体发现与递归扫描实时进度：页面内 `blob:` 资源现在会安全进入结果库，并在独立“可能资源”分类中显示数量、临时资源警告和人工确认提示；它们始终不可下载，也不会进入后台网络访问或下载队列。

递归扫描会实时显示当前正在请求的 URL 和最近一分钟真实请求数，慢请求结束后会清除过期速率。侧边栏现在正确合并进度事件，任务完成、失败或取消后立即移出未完成列表；迟到的运行事件不会再把终态任务回退为运行中。

UI 增加清晰的按钮按压反馈并完整遵守 reduced-motion。真实 Microsoft Edge E2E 已实际完成 TXT、CSV、JSON、历史导出与下载队列落盘，同时检查 280px、320px、380px 侧栏、可访问名称、按钮目标尺寸，以及清空历史不会误删下载记录和设置。

WebFile Hunter 仍完全本地运行，不上传扫描数据，默认静音，不播放音效或背景音乐。
