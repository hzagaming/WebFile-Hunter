# 1.3.0

WebFile Hunter 1.3.0 新增独立“文本”侧栏。当前页、权限允许的 frame 与同源递归页面现在可以提取公开可见正文，并按页面切换、关键词计数、复制或导出 TXT。文本始终以纯文本渲染，完全保存在本地。

隐私边界同步加固：正文提取不会读取显式隐藏内容、脚本样式、模板、输入框、密码、文本框、下拉选项或 `contenteditable` 草稿，也不执行 OCR。单页与单任务均有字符和文档数量硬上限；删除任务、清空历史或过期清理会同时移除对应正文。

资源发现新增常见的懒加载 `data-srcset`、背景、缩略图、文件 URL 属性，以及 SVG `use`/`feImage` 引用。动态监听只继续发送资源批次，不会高频重复传输整页正文；用户可在文本页明确点击重新提取。

真实 Microsoft Edge E2E 已覆盖公开正文、开放 Shadow DOM、跨域 frame、同源递归、隐私过滤、搜索、复制、TXT 导出和 280/320/380px 六页侧栏。扩展仍完全本地运行，不上传扫描数据，默认静音，不播放音效或背景音乐。
