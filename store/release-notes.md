# 1.6.0

WebFile Hunter 1.6.0 让媒体结果更容易辨认和使用。图片结果卡会直接显示延迟加载的小缩略图，点击即可放大；音频结果卡会显示时长，并可在卡内手动播放或暂停。切换音频时会停止上一段媒体，加载失败会显示明确状态，扩展不会自动播放任何音频。

结果搜索现在会统一全角/半角字符、清理首尾空格，并支持多个关键词全部匹配。匹配范围扩展到文件名、最终 URL、扩展名、MIME、分类、来源页、发现来源及风险标签；扩展名筛选改为去除开头点号后的精确匹配，减少近似扩展名误命中。

每个结果的“打开”按钮会在新标签页打开资源，“下载”按钮独立创建并只启动当前文件，不会误启动队列中的其他任务；浏览器拒绝启动时会显示真实错误。媒体请求统一使用 `no-referrer`；`blob:`、分段流和无效资源继续禁止预览、打开及直接下载。超长 URL 和六按钮结果卡在窄侧栏下不会裁切。

真实 Microsoft Edge E2E 覆盖卡内图片实际加载、音频解码/时长/播放暂停、全角多关键词搜索、新标签页打开、单项下载隔离与真实落盘，以及 280/320/380px 界面。扩展继续完全本地运行，默认静音，不播放 SFX 或 BGM；音频只响应用户点击。
