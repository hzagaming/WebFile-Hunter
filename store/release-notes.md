# 1.9.0

WebFile Hunter 1.9.0 集中提升文件识别准确度。当前 DOM 与递归 HTML 现在使用统一的 `srcset` 解析器，资源 URL 内部的逗号不会再被错误截断；用户在设置中添加的自定义扩展名会贯通页面发现、后台过滤和递归分类，`name=file.ext` 一类查询文件名也能进入正确链路。

CSS 解析会忽略字符串中的伪 `url()` 与 `@import`，并正确处理十六进制转义和转义右括号。递归扫描只继续解析合理的 CSS 响应，JSON 等明确非 CSS 内容不会产生伪资源。手动元数据探测新增可持久化的探测中、完成和失败状态，并在返回通用二进制 MIME 时保留用户自定义分类。

正文隐私与 Frame 隔离同步加固：折叠 `<details>` 中的直接文本不会泄漏，跨域 Frame 正文使用自身地址保存，不再覆盖主页面。完整嗅探与递归配置的 ARIA 关联、启动期间的重复操作、异步选择状态、虚拟列表子控件方向键和受限页面文字入口均已修正；下载确认设置也明确同时作用于单项与批量。

发布回归覆盖全量单元与组件测试、覆盖率、TypeScript、ESLint、Prettier、Manifest、生产构建和真实 Microsoft Edge E2E，包括图片缩略图、音频手动试听、网页文字、递归扫描、键盘焦点、真实下载与 280/320/380px 窄侧栏。扩展继续完全本地运行，默认静音，不播放 SFX 或 BGM；音频只响应用户点击。
