# 1.11.0

WebFile Hunter 1.11.0 新增可自定义的网站授权。设置页默认识别当前 HTTP/HTTPS 网站，也可关闭自动识别后填写 `google.com` 一类裸域名或完整 URL；裸域名会同时申请 HTTP 与 HTTPS，完整 URL 只申请对应协议。无效协议、凭据、通配符和非法地址会在请求权限前被拒绝。

授权继续严格由用户点击触发，界面以浏览器真实权限快照为准。已有完整权限时不会显示并不存在的冗余单站条目；单站与完整权限撤销会校验实际结果并刷新全局状态。用户从 Edge 权限面板增删网站权限后，设置页、结果能力与对应运行任务也会立即同步。

本版深度复查扫描、递归、下载、存储、消息校验、结果卡、图片缩略图、音频手动试听、预览弹层、键盘焦点、reduced-motion 和 280/320/380px 窄侧栏。扩展继续完全本地运行，默认静音，不播放 SFX 或 BGM；音频只响应用户点击。

发布回归覆盖全量单元与组件测试、覆盖率、TypeScript、ESLint、Prettier、Manifest、生产构建、发布 ZIP 和真实 Microsoft Edge E2E；新增默认/自定义授权、非法输入、真实权限回读及浏览器权限事件验证。
